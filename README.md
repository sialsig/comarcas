# Comarcas y municipios de España

Página (`index.html`) para buscar por comarca (oficial o agraria) o por municipio, con provincia, comunidad autónoma y habitantes (hombres y mujeres), y descargar los resultados en Excel.

- Población: INE, cifras oficiales del padrón municipal a 1/1/2025 (RD 1117/2025).
- Comarcas oficiales: Cataluña (Idescat), Navarra (LF 4/2019), Andalucía (Orden 14/3/2003), Aragón (IAEST), Galicia (IGE), País Vasco (Eustat), Asturias (SADEI) y El Bierzo (Ley 1/1991).
- Comarcas agrarias: Ministerio de Agricultura, para todos los municipios.

Datos de `syner_core.ref_municipios` (Syner), a 25/10/2026.
